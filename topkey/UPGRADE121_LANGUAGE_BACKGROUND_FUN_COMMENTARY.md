# Upgrade121

## Language
The Hub reads `topkey_ui_language_v1`. The language modal opens only if this key has never been set. Returning to the Hub keeps the selected language.

## Backgrounds
Seven local SVG backgrounds live under `assets/backgrounds/`. VNext picks the image from the `sport` query parameter; Badminton uses its dedicated background. All backgrounds are local, lightweight and overlaid with a dark layer for readability.

## Badminton fun commentary
The Live & BLV card adds a player selector populated from the active match on the selected court, a curated safe phrase list, random phrase button and manual speak button. Phrases are intentionally positive and exclude mocking, aggression, money/gambling and disparagement.
