# Upgrade122 Hotfix59 - BTC System Role

BTC is now a first-class built-in role in Badminton and all MultiSport VNext modules.

Default BTC permissions:
- Overview: view
- Control: edit
- Teams / Check-in: edit
- Schedule / Standings: edit
- Umpire: view
- Live / Commentary: edit
- Finance: view
- Announcements: edit
- Audit: view
- Health: view
- Settings: view

ADMIN remains the only role that can create Firebase accounts or manage security-sensitive system administration.
